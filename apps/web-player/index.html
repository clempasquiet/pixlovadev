pixlova Player

Ce bouton passe en plein écran et autorise le son. En mode kiosque, le navigateur peut l’autoriser par sa configuration (par exemple Chrome --kiosk --autoplay-policy=no-user-gesture-required).

Un Player Web dépend de son navigateur : l’effacement des données du site, un changement de profil ou l’éviction du stockage imposent un nouvel appairage ou un nouveau téléchargement. Pour une diffusion autonome garantie, utilisez le Player natif.

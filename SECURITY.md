# Sécurité

pixlova est en préparation. Aucune version de production n’est encore déclarée supportée dans ce dépôt.

Pour signaler une vulnérabilité, utiliser le signalement privé GitHub s’il est activé, ou un canal privé déjà convenu avec le propriétaire du dépôt. Ne pas publier de secret, média client, cookie, dump ou détail d’exploitation sensible dans un ticket public. Aucun canal de signalement public fictif n’est fourni.

Les exigences de sécurité figurent dans le [chapitre 12](docs/spec/chapters/12.md). Les réglages GitHub de protection, de revue et de détection de secrets sont recensés dans [l’exploitation du dépôt](docs/agents/REPOSITORY.md) ; seuls les réglages vérifiés comme actifs peuvent être considérés appliqués.
